# SPECIFICATION: Subscription & Local vs Cloud Tiers

> **Feature**: Tiering & Offline Execution Policy

---

## 1. Tiers

- **Local BYOK Tier**: 100% Free, runs offline or with user's own API keys.
- **Pro Cloud Tier**: Unlimited managed cloud AI model access, WebRTC voice streaming servers, and cloud backup.

## 2. Privacy Guarantee

- Data never leaves local device when running in BYOK / Local Ollama mode.
