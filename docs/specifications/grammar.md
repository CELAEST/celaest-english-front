# SPECIFICATION: Grammar Mastery Engine

> **Feature**: Contextual Syntax & Grammar Explanations

---

## 1. Entrance & Exit

- **Entrance**: Selecting "Grammar" from Learn sidebar or clicking "Why is this better?" on a memory card.
- **Exit**: Close drawer or return to Learning Hub.

---

## 2. User Actions & Flow

1. User views grammar pattern (e.g. _Present Perfect vs Past Simple_).
2. Interactive sentence builder lets user toggle auxiliary verbs (`have` / `has` / `had`).
3. Real-time AI explanation drawer updates automatically.

---

## 3. UI States & Edge Cases

- **States**: Card view, Interactive toggle active, Drawer expanded.
- **Edge Case**: If user inputs an uncommon edge case sentence, AI generates a custom rule explainer dynamically.
