# SPECIFICATION: Vocabulary Expansion Module

> **Feature**: Contextual Professional Vocabulary Clusters

---

## 1. Entrance & Exit

- **Entrance**: Clicking "Vocabulary" in Learn menu or adding word from Reading Studio.
- **Exit**: Close module -> Return to Workspace.

---

## 2. User Actions & Flow

1. View active word cards organized by industry domain (e.g. Executive Tech, System Architecture, Business Negotiation).
2. Tap word card to hear audio pronunciation, view collocations, and see example sentences.
3. Mark word mastery (`To Review`, `Learning`, `Mastered`).

---

## 3. UI States & Edge Cases

- **States**: Grid view, Expanded detail modal, Filtered state by domain.
- **Data Output**: Updated spaced repetition intervals in local memory database.
