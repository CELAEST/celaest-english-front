# SPECIFICATION: Progress & Analytics Dashboard

> **Feature**: Fluency Metrics & Speaking Pace Graphs

---

## 1. Metrics Tracked

- **Grammar Accuracy %** (e.g. 82%)
- **Vocabulary Range %** (e.g. 74%)
- **Speaking Fluency & Pace** (e.g. 81%, 135 WPM)
- **Weekly Practice Streak & Volume**

## 2. UI Components

- Circular SVG `ProgressRing` gauges.
- Smooth line graph showing weekly WPM and hesitation drop.
