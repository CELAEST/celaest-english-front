# SPECIFICATION: Professional Writing Lab

> **Feature**: AI Proofreader & Tone Analyzer  

---

## 1. Entrance & Exit
- **Entrance**: Clicking "Writing" in sidebar.
- **Exit**: Submitting text -> AI Reflection screen -> Workspace.

---

## 2. User Actions & Flow
1. Select writing prompt (e.g. *"Write an email to a client explaining a project update"*).
2. Type in markdown-enabled dark editor text area.
3. View live word count and target timer.
4. Real-time AI proofreader highlights weak vocabulary and tone mismatches.
5. Click "Submit for feedback" -> Full AI breakdown generated.

---

## 3. UI States & Edge Cases
- **States**: Editor view, Live proofreading active, Submitting, AI Review summary screen.
- **Data Output**: Detailed writing metrics (Structure score, conciseness %, new expressions saved to Memory Bank).
