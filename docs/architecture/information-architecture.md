# INFORMATION ARCHITECTURE: Lingua System Tree

```
Lingua Platform
│
├── 0. Splash & Onboarding
│   ├── Welcome & Mission Statement
│   ├── Step 1: Career & Focus Goal Discovery
│   ├── Step 2: Proficiency & Confidence Assessment
│   ├── Step 3: Preferred Practice Cadence
│   └── Step 4: Learning DNA Generation & Blueprint Summary
│
├── 1. Authentication & Security
│   ├── Login / Register (Local Vault or Cloud)
│   ├── Forgot / Reset Security Credentials
│   └── BYOK Key Setup (OpenAI, Anthropic, DeepSeek, Ollama)
│
├── 2. Dashboard Workspace
│   ├── Daily Focus Card & Next Milestone
│   ├── Ambient AI Mentor Greeting & Context
│   ├── Quick Action Triggers (Start Conversation, Practice Interview)
│   └── "Your Journey" Horizontal Timeline Stream
│
├── 3. Learn Modules
│   ├── Speaking (Real-time phonetic drills & pace tracker)
│   ├── Vocabulary (Contextual word clusters & memory cards)
│   ├── Grammar (Interactive syntax explainers & pattern cards)
│   ├── Reading (Active Reading Studio, inline lookup, focus mode)
│   └── Writing (Professional Writing Lab, AI tone check, reflection)
│
├── 4. Real-time Conversation Hub
│   ├── Live Voice Session (Interactive 3D/Canvas Orb)
│   ├── Text Chat Stream & Audio Waveform Visualizer
│   └── Conversation History & Session Transcripts
│
├── 5. Progress & Memory Engine
│   ├── Analytics (Fluency score, speaking pace, weekly graphs)
│   ├── Memory Bank (Flip-card spaced repetition: To Review, Learning, Mastered)
│   └── Knowledge Graph (Interactive 2D/3D skill topology tree)
│
└── 6. Settings & Security
    ├── Profile (User details, target level B1/B2/C1)
    ├── AI Providers (API keys, model selection, local Ollama host)
    ├── Notifications (Smart reminder preferences)
    └── Security & Privacy (Local data vault export/purge, AES-GCM settings)
```
